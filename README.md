### Ignacio García Ribelles

Biostatistics and data science for biomarkers and diagnostics, in R. Bioinformatician at University Hospital Tübingen, relocating to Barcelona.

- **Work:** immune monitoring of a peptide-vaccine trial with Bayesian hierarchical models of assay variance; assay positivity cut-offs derived from the lab's own replicates; survival analysis of a tumour-board cohort; tested R and Nextflow pipelines that biologists run themselves. That code lives in private lab repositories.
- **Public projects:**
  - [adam-admiral-walkthrough](https://github.com/Ngarciar24/adam-admiral-walkthrough): ADaM for the CDISC pilot study with {admiral}, define.xml and the primary efficacy analysis, checked against the published pilot ([read it](https://ngarciar24.github.io/adam-admiral-walkthrough/)).
  - [diagnostic-biostatistics-r](https://github.com/Ngarciar24/diagnostic-biostatistics-r): precision, limits of detection, ROC and cut-offs, sample size, companion-diagnostic bridging and a mock SAP, on simulated data ([read it](https://ngarciar24.github.io/diagnostic-biostatistics-r/)).
- **Community:** code reviewer for nf-core/epitopeprediction and nf-core/mhcquant.
- **Publication:** Soll et al., *Nature Immunology* (2024): flow cytometry and single-cell RNA-seq analyses.
