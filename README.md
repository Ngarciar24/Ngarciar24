### Ignacio Garcia Ribelles

Bioinformatician and data scientist working in R and Python at University Hospital Tübingen.

- **Work:** immune monitoring of a vaccine cohort with Bayesian hierarchical models of assay variance; assay positivity cut-offs derived from the lab's own replicates; survival analysis of a tumour-board cohort; tested R and Nextflow pipelines that biologists run themselves. Most of that code lives in private lab repositories.
- **Public projects:**
  - [adam-admiral-walkthrough](https://github.com/Ngarciar24/adam-admiral-walkthrough): ADaM for the CDISC pilot study with {admiral}, define.xml and the primary efficacy analysis, checked against the published pilot results with an independent Python cross-check ([site](https://ngarciar24.github.io/adam-admiral-walkthrough/)).
  - [diagnostic-biomarker-statistics](https://github.com/Ngarciar24/diagnostic-biomarker-statistics): diagnostic and biomarker statistics in R: precision, limits of detection, ROC and cut-offs (reproducing a published FDA decision summary), sample size, companion-diagnostic bridging, prediction-model validation, time-to-event and propensity-score analyses, and a mock SAP with a Python/SQL re-derivation ([read the book](https://ngarciar24.github.io/diagnostic-biomarker-statistics/)).
- **Community:** code reviewer for [nf-core/epitopeprediction](https://github.com/nf-core/epitopeprediction) and [nf-core/mhcquant](https://github.com/nf-core/mhcquant).
- **Publication:** [Soll et al., *Nature Immunology* (2024)](https://www.nature.com/articles/s41590-024-01918-6): contributed to the flow cytometry and single-cell RNA-seq analyses.
